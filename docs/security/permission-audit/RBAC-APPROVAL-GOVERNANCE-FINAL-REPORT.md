## Decisions implemented

- Preserve canonical granular View/Action keys, multi-role membership, direct user Allow/Deny behavior, default deny, tenant/resource checks, and descriptive role categories. Do not add wildcards, role inheritance, or role-level Deny.
- Protect the existing tenant-scoped `tenant.admin` identity with a 63-key Protected Core. New Tenant Admin provisioning receives all active assignable non-reserved grants except the explicit `Program.CreateAcrossPortfolios` opt-in. Existing Admin grants are preserved; reseeding restores Core only and does not restore optional Project Settings grants.
- Keep the External Licensing integration and protected-account recovery deferred until an authenticated provider and recovery contract are approved.
- Deny Payment Request self-approval by default while no saved request-type exception policy exists. Approval still requires permission, project scope, assignment, active project-team eligibility, and valid workflow state.
- Permit Payment Request approver recovery only through both `ProjectPaymentRequest.Approve` and `Governance.AssignmentRecovery.Manage`, with active eligible replacement, request version, reason, and audit record. Do not auto-approve or skip stages.
- Permit Payment Reversal and Year-End Closing reassignment only through the workflow approval permission plus Governance.AssignmentRecovery.Manage, with active eligible replacements, current assignee ineligibility, version checks, reason, and audit. Year-End Closing recovery cancellation is allowed only when the selected pending assignee is ineligible and no eligible replacement exists. Do not auto-approve or skip stages.
- Preserve mandatory Project Sponsor assignments in Change Request workflows: a mandatory sponsor slot can only be reassigned to an eligible sponsor.
- Organize Roles permission editing by six bilingual business modules and the existing feature/screen; place Project-scope finance in Project Management and Portfolio/Program rollups in Portfolio & Program Management. Do not reintroduce role-category grant restrictions.
